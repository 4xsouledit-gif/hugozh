参与主题

把自制 Hugo 主题提交到社区主题目录的方式。

概述

社区为 Hugo 创建了大量主题。可以访问 themes.gohugo.io 浏览这些主题，找到适合自己站点的样式与结构。

如果你已经构建了一个主题，并希望回馈 Hugo 社区，可以把它分享出来，提交到社区主题目录，供其他用户浏览与使用。主题是社区生态的一部分，创建或改进主题也是参与 Hugo 项目的方式之一。

提交主题

提交自己的主题只需要两步：

  1. 阅读提交指南；
  2. 在主题仓库中开一个拉取请求。

社区主题站点由主题仓库构建和维护，提交所需的格式要求与注意事项都写在它的 README 中，提交前请先完整阅读，以免因格式不符而需要返工。

其他主题目录

除了官方社区主题站点，还可以在下列主题目录中浏览或提交主题：

  • jamstack.club
  • jamstackthemes.dev

补充说明

主题通常放在项目的 themes/ 目录中，也可以通过 Hugo 模块引入；无论采用哪种方式使用主题，都不影响向社区主题目录提交。
