集合函数

用这些函数操作与查询映射（map）、切片（slice）和字符串。

本章内容

  • collections.After 返回给定切片中位于前 N 个元素之后的元素所组成的切片。 2026年10月2日（今天）
  • collections.Append 把单个或多个元素，或者另一个完整切片，追加到给定切片的末尾并返回新切片。 2026年10月2日（今天）
  • collections.Apply 用指定的函数及参数逐个转换给定切片的元素，返回新切片。 2026年10月2日（今天）
  • collections.Complement 找出只出现在最后一个给定切片中、而不出现在前面任何切片中的元素，返回这些元素组成的切片。 2026年10月2日（今天）
  • collections.D 根据给定的种子、数量和最大值，返回一个已排序且互不重复的随机整数切片。 2026年10月2日（今天）
  • collections.Delimit 用指定的分隔符连接给定切片或映射中的值，返回一个字符串。 2026年10月2日（今天）
  • collections.Dictionary 根据给定的键值对创建一个映射（map）。 2026年10月2日（今天）
  • collections.First 返回给定切片或字符串的前 N 个元素。 2026年10月2日（今天）
  • collections.Group 按指定 key 对给定的页面集合（切片）分组，返回一个映射。 2026年10月2日（今天）
  • collections.In 报告某个值是否存在于给定的切片或字符串中。 2026年10月2日（今天）
  • collections.Index 按指定的一个或多个 key，从给定的切片或映射中取出元素或值。 2026年10月2日（今天）
  • collections.Intersect 返回两个给定切片中的公共元素，顺序与第一个切片一致。 2026年10月2日（今天）
  • collections.IsSet 报告给定的映射或切片中是否存在指定的 key 或索引。 2026年10月2日（今天）
  • collections.KeyVals 把给定的 key 与一组值配对，返回一个 KeyVals 结构。 2026年10月2日（今天）
  • collections.Last 返回给定切片或字符串的最后 N 个元素。 2026年10月2日（今天）
  • collections.Merge 把两个或多个给定映射合并为一个映射并返回。 2026年10月2日（今天）
  • collections.NewScratch 返回一个局部作用域的持久化数据结构，用于存储和操作带 key 的值。 2026年10月2日（今天）
  • collections.Querify 根据给定的映射、切片或键值对序列，返回 URL 查询字符串。 2026年10月2日（今天）
  • collections.Reverse 把给定切片中的元素顺序反转后返回。 2026年10月2日（今天）
  • collections.Seq 返回一个整数切片：从 1 或指定值开始，按 1 或指定步长递增，到指定值结束。 2026年10月2日（今天）
  • collections.Shuffle 把给定切片中的元素顺序随机打乱后返回。 2026年10月2日（今天）
  • collections.Slice 根据给定的值创建一个切片。 2026年10月2日（今天）
  • collections.Sort 按指定的 key 与顺序重排给定集合，返回排序后的映射或切片。 2026年10月2日（今天）
  • collections.SymDiff 返回两个给定切片的对称差集（symmetric difference）。 2026年10月2日（今天）
  • collections.Union 返回两个给定切片中的全部不重复元素。 2026年10月2日（今天）
  • collections.Uniq 去掉给定切片中的重复元素后返回。 2026年10月2日（今天）
  • collections.Where 按指定的 key、运算符和值筛选给定切片，返回满足条件的元素。 2026年10月2日（今天）
