Hugo 函数

用这些函数获取 Hugo 应用程序与当前运行环境的信息。

本章导读

hugo 命名空间下的函数返回的是构建环境自身的信息，而不是内容或页面数据：Hugo 的版本号与编译信息、运行环境名称、站点是否多语言或多主机、项目工作目录、全局存储等。

这些值常用于条件渲染，例如只在生产环境输出统计脚本、在开发服务器上显示调试信息，或按版本号决定是否启用某个参数。

本章内容

  • hugo.BuildDate 返回 Hugo 二进制的编译日期。 2026年10月2日（今天）
  • hugo.CommitHash 返回 Hugo 二进制的 Git 提交哈希。 2026年10月2日（今天）
  • hugo.Data 返回由 data 目录中的文件构成的数据结构。 2026年10月2日（今天）
  • hugo.Deps 返回项目依赖的切片，依赖可以是模块，也可以是本地主题组件。 2026年10月2日（今天）
  • hugo.Environment 返回当前运行的环境。 2026年10月2日（今天）
  • hugo.Generator 返回一个 HTML meta 元素，用于标明生成本站的软件。 2026年10月2日（今天）
  • hugo.GoVersion 返回编译 Hugo 二进制所用的 Go 版本。 2026年10月2日（今天）
  • hugo.IsDevelopment 报告当前运行环境是否为 development。 2026年10月2日（今天）
  • hugo.IsExtended 报告 Hugo 二进制是 extended 版还是 extended/deploy 版。 2026年10月2日（今天）
  • hugo.IsMultihost 报告每个已配置的语言是否拥有各自独立的 base URL。 2026年10月2日（今天）
  • hugo.IsMultilingual 报告是否配置了两个或更多语言。 2026年10月2日（今天）
  • hugo.IsProduction 报告当前运行环境是否为 production。 2026年10月2日（今天）
  • hugo.IsServer 报告内置开发服务器是否正在运行。 2026年10月2日（今天）
  • hugo.Sites 返回所有维度上全部站点的集合。 2026年10月2日（今天）
  • hugo.Store 返回一个全局作用域的持久数据结构，用于存取与操作键值对。 2026年10月2日（今天）
  • hugo.Version 返回 Hugo 二进制的当前版本。 2026年10月2日（今天）
  • hugo.WorkingDir 返回项目的工作目录。 2026年10月2日（今天）
