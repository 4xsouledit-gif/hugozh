images

images.Config

返回指定路径（相对于工作目录）图像对应的 image.Config 结构。

签名
images.Config PATH
返回类型
image.Config

说明

这是一个旧版（legacy）函数，已被全局资源、页面资源和远程资源的 Width 与 Height 方法取代。详见图像处理一节。

{{ $ic := images.Config "/static/images/a.jpg" }}

{{ $ic.Width }} → 600 (int)
{{ $ic.Height }} → 400 (int)

支持的图像格式包括 AVIF、BMP、GIF、HEIC、HEIF、JPEG、PNG、TIFF 和 WebP。

Hugo 会缓存结果，因此用同一路径多次调用该函数不会带来额外开销。
