图像函数

用这些函数创建图像滤镜、把图像滤镜应用到图像上，以及读取图像信息。

本章内容

  • images.AutoOrient 返回一个图像滤镜，按图像的 Exif 方向标记自动旋转和翻转图像。 2026年10月2日（今天）
  • images.Brightness 返回一个改变图像亮度的图像滤镜。 2026年10月2日（今天）
  • images.ColorBalance 返回一个改变图像色彩平衡的图像滤镜。 2026年10月2日（今天）
  • images.Colorize 返回一个生成图像着色版本的图像滤镜。 2026年10月2日（今天）
  • images.Config 返回指定路径（相对于工作目录）图像对应的 image.Config 结构。 2026年10月2日（今天）
  • images.Contrast 返回一个改变图像对比度的图像滤镜。 2026年10月2日（今天）
  • images.Dither 返回一个对图像做抖动（dither）处理的图像滤镜。 2026年10月2日（今天）
  • images.Filter 返回一个新的图像资源，它是把一个或多个图像滤镜应用到给定图像资源后得到的结果。 2026年10月2日（今天）
  • images.Gamma 返回一个对图像做伽马校正的图像滤镜。 2026年10月2日（今天）
  • images.GaussianBlur 返回一个对图像做高斯模糊的图像滤镜。 2026年10月2日（今天）
  • images.Grayscale 返回一个生成图像灰度版本的图像滤镜。 2026年10月2日（今天）
  • images.Hue 返回一个旋转图像色相的图像滤镜。 2026年10月2日（今天）
  • images.Invert 返回一个把图像颜色取反的图像滤镜。 2026年10月2日（今天）
  • images.Mask 返回一个对源图像应用遮罩的图像滤镜。 2026年10月2日（今天）
  • images.Opacity 返回一个改变图像不透明度的图像滤镜。 2026年10月2日（今天）
  • images.Overlay 返回一个把源图像叠加到指定坐标（相对左上角）的图像滤镜。 2026年10月2日（今天）
  • images.Padding 返回一个只改变图像画布尺寸、不缩放图像本身的图像滤镜。 2026年10月2日（今天）
  • images.Pixelate 返回一个对图像做像素化（pixelate）处理的图像滤镜。 2026年10月2日（今天）
  • images.Process 返回一个按给定处理规格处理图像的图像滤镜。 2026年10月2日（今天）
  • images.QR 按指定选项把给定文本编码为二维码，返回一个包含该二维码的图像资源。 2026年10月2日（今天）
  • images.Saturation 返回一个改变图像饱和度的图像滤镜。 2026年10月2日（今天）
  • images.Sepia 返回一个生成图像棕褐色（sepia）版本的图像滤镜。 2026年10月2日（今天）
  • images.Sigmoid 返回一个用 S 形函数改变图像对比度的图像滤镜。 2026年10月2日（今天）
  • images.Text 返回一个为图像添加文字的图像滤镜。 2026年10月2日（今天）
  • images.UnsharpMask 返回一个锐化图像的图像滤镜。 2026年10月2日（今天）
