字符串函数

用这些函数处理字符串。

本章内容

  • strings.Chomp 返回给定字符串，并删除末尾的所有换行符与回车符。 2026年10月2日（今天）
  • strings.Contains 报告给定字符串是否包含指定子串。 2026年10月2日（今天）
  • strings.ContainsAny 报告给定字符串是否包含指定字符集合中的任意字符。 2026年10月2日（今天）
  • strings.ContainsNonSpace 报告给定字符串是否包含 Unicode 定义的非空白字符。 2026年10月2日（今天）
  • strings.Count 返回给定子串在给定字符串中不重叠出现的次数。 2026年10月2日（今天）
  • strings.CountRunes 返回给定字符串中除空白字符之外的 rune 数量。 2026年10月2日（今天）
  • strings.CountWords 返回给定字符串中的单词数量。 2026年10月2日（今天）
  • strings.FindRE 返回与正则表达式匹配的字符串切片。 2026年10月2日（今天）
  • strings.FindRESubmatch 返回正则表达式全部连续匹配构成的切片，其中每个元素也是一个切片，依次保存最左侧匹配的文本及其各子表达式的匹配结果。 2026年10月2日（今天）
  • strings.FirstLower 返回给定字符串，并把第一个字符转为小写。 2026年10月2日（今天）
  • strings.FirstUpper 返回给定字符串，并把第一个字符转为大写。 2026年10月2日（今天）
  • strings.HasPrefix 报告给定字符串是否以指定前缀开头。 2026年10月2日（今天）
  • strings.HasSuffix 报告给定字符串是否以指定后缀结尾。 2026年10月2日（今天）
  • strings.Repeat 返回把给定字符串重复指定次数后的结果。 2026年10月2日（今天）
  • strings.Replace 返回给定字符串，并把其中所有 OLD 替换为 NEW。 2026年10月2日（今天）
  • strings.ReplacePairs 返回给定字符串，并用一组旧新字符串对在一次扫描中完成多处替换。 2026年10月2日（今天）
  • strings.ReplaceRE 返回给定字符串，并把所有与正则表达式匹配的部分替换为替换模式。 2026年10月2日（今天）
  • strings.RuneCount 返回给定字符串中的 rune 数量。 2026年10月2日（今天）
  • strings.SliceString 返回给定字符串的子串，从起始位置开始，到结束位置之前结束。 2026年10月2日（今天）
  • strings.Split 按分隔符切分给定字符串，返回字符串切片。 2026年10月2日（今天）
  • strings.Substr 返回给定字符串的子串，从起始位置开始，到给定长度之后结束。 2026年10月2日（今天）
  • strings.Title 返回给定字符串，并转换为标题式大小写。 2026年10月2日（今天）
  • strings.ToLower 返回给定字符串，并把所有字符转为小写。 2026年10月2日（今天）
  • strings.ToUpper 返回给定字符串，并把所有字符转为大写。 2026年10月2日（今天）
  • strings.Trim 返回给定字符串，并删除 cutset 中指定的首尾字符。 2026年10月2日（今天）
  • strings.TrimLeft 返回给定字符串，并删除 cutset 中指定的开头字符。 2026年10月2日（今天）
  • strings.TrimPrefix 返回给定字符串，并从开头删除指定前缀。 2026年10月2日（今天）
  • strings.TrimRight 返回给定字符串，并删除 cutset 中指定的结尾字符。 2026年10月2日（今天）
  • strings.TrimSpace 返回给定字符串，并删除 Unicode 定义的首尾空白字符。 2026年10月2日（今天）
  • strings.TrimSuffix 返回给定字符串，并从结尾删除指定后缀。 2026年10月2日（今天）
  • strings.Truncate 返回给定字符串，截断到最大长度，同时不切断单词、不留下未闭合的 HTML 标签。 2026年10月2日（今天）
