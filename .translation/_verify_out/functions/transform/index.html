转换函数

用这些函数把取值从一种格式转换为另一种格式。

本章内容

  • transform.CanHighlight 报告给定语言是否支持语法高亮。 2026年10月2日（今天）
  • transform.Emojify 返回把 emoji 短代码替换为对应 emoji 字符后的给定字符串。 2026年10月2日（今天）
  • transform.Highlight 返回用语法高亮器渲染后的给定代码。 2026年10月2日（今天）
  • transform.HighlightCodeBlock 返回代码块渲染钩子上下文中收到的、已高亮的代码。 2026年10月2日（今天）
  • transform.HTMLEscape 返回把特殊字符替换为 HTML 实体后的给定字符串。 2026年10月2日（今天）
  • transform.HTMLToMarkdown 返回转换为 Markdown 后的给定 HTML。 2026年10月2日（今天）
  • transform.HTMLUnescape 返回把每个 HTML 实体替换为对应字符后的给定字符串。 2026年10月2日（今天）
  • transform.Markdownify 返回渲染为 HTML 后的给定 Markdown。 2026年10月2日（今天）
  • transform.Plainify 返回删除所有 HTML 标签后的字符串。 2026年10月2日（今天）
  • transform.PortableText 返回转换为 Markdown 后的给定 Portable Text。 2026年10月2日（今天）
  • transform.Remarshal 返回按指定格式序列化后的字符串，它由一串序列化数据或一个映射编组而成。 2026年10月2日（今天）
  • transform.ToMath 返回把用 LaTeX 语言书写的给定数学标记渲染为 HTML 后的结果。 2026年10月2日（今天）
  • transform.Unmarshal 返回从 CSV、JSON、TOML、YAML 或 XML 格式的序列化数据解析出的映射或数组。 2026年10月2日（今天）
  • transform.XMLEscape 返回删除不允许的字符后再转义为对应 XML 形式的给定字符串。 2026年10月2日（今天）
