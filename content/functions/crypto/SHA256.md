## 这一页解决什么问题

`sha256` 给输入算 SHA-256 摘要，返回 64 位十六进制字符串。它是本站推荐的安全哈希：签名、校验、`fingerprint` 都基于它。

## 什么时候用，什么时候别用

**该用**：

- 校验和、完整性校验、缓存键（安全要求高的场合）；
- 构造 SRI 哈希（也可用 [`crypto.Hash`](/functions/crypto/hash/) 动态选算法）；
- 需要与 SHA-256 实现对接。

**别用**：

- 需要带密钥 → 用 [`crypto.HMAC`](/functions/crypto/hmac/)；
- 只要短的非加密指纹 → 用 [`hash.FNV32a`](/functions/hash/fnv32a/) / [`hash.XxHash`](/functions/hash/xxhash/)；
- 资源指纹 → 对 resource 用 `fingerprint`（省去手工拼接）。

```go-html-template
{{ sha256 "Hello world" }} → 64ec88ca00b268e5ba1a35678a1b5316d212f4f366b2477232534a8aeca37f3c
```

## 完整示例（实测）

```go-html-template
{{ sha256 "Hello world" }} → 64ec88ca00b268e5ba1a35678a1b5316d212f4f366b2477232534a8aeca37f3c
{{ sha256 "" }}            → e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
{{ sha256 "中文" }}         → 72726d8818f693066ceb69afa364218b692e62ea92b385782363780f47529c21
{{ sha256 42 }}            → 73475cb40a568e8da8a045ced110137e159f890ac4da883b6b17dc651b3a8049
```

Hugo 0.167.0 实测：以上逐条与 `→` 后一致（`sha256 ""` 与 `crypto.Hash "sha256" ""` 相同）；数字先转成字符串再计算。

## 返回值边界（实测）

| 输入 | 结果 | 是否报错 |
| --- | --- | --- |
| `"Hello world"` | `64ec88ca00b268e5ba1a35678a1b5316d212f4f366b2477232534a8aeca37f3c` | 否 |
| 空字符串 | `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855` | 否 |
| 非 ASCII（`"中文"`） | `72726d8818f693066ceb69afa364218b692e62ea92b385782363780f47529c21`（按 UTF-8 字节计算） | 否 |
| 非字符串（`42`） | 按字符串 `"42"` 计算 | 否 |
| 返回类型 | `string`（64 位十六进制，小写） | 否 |
