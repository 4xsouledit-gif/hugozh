这一章对应 Hugo 官方文档的 About 章节，回答「Hugo 是什么、能做什么、以什么方式发布、在安全上如何划界」这几个问题，适合在动手之前快速了解，也适合在选型或做安全评估时查阅。

## 这一页解决什么问题

这一页是本章的入口。它不重复各页的技术细节，只解决两个问题：**先读哪一页**，以及**读完这一章你应该带走什么结论**。各页的具体内容见下文「本章各页分别介绍」。

本章四页回答的是四个不同的问题，按需取用即可：想知道「值不值得用」看简介与特性；要评估「把构建流程交给它有没有风险」看安全模型；只有再分发 Hugo 本体或修改它的源码时，许可页才产生实际约束。

## 读完本章你应该能够

- 用一句话说明 Hugo 是什么、它产出什么，以及它和「带后台编辑界面的 CMS」的差别；
- 对照[特性](/about/features/)判断多语言、图像处理、Sass、短代码这类需求在 Hugo 里靠哪一项实现，并知道哪些要额外装东西或改配置；
- 说出 Hugo 安全模型的信任边界：模板与配置可信、内容不可信，唯一例外是内联短代码；
- 用 `hugo config --printZero` 打印自己站点实际生效的默认安全策略，并据此核对某项设置到底有没有生效；
- 读懂 Apache 2.0 许可对「使用、修改、再分发」分别要求什么，以及第 6 节为什么不授予商标许可。

## 建议阅读顺序

1. **[简介](/about/introduction/)** —— 先弄清 Hugo 是什么、产物形态、开发与部署的分工，约 5 分钟。
2. **[特性](/about/features/)** —— 按分区浏览，找到与自己需求相关的条目再点进去看做法；本页也给出判断「这一特性在你的版本里能不能用」的命令。
3. **[安全模型](/about/security/)** —— 只要站点内容不是全部由你自己撰写，就建议读一遍。它把默认安全策略逐条对应到配置键，可以自己动手核对。
4. **[许可](/about/license/)** —— 只在你使用、修改或再分发 Hugo 本体时才产生实际约束；只用它构建站点的话，扫一遍结论表即可。

初次接触 Hugo 的读者可以先读简介与特性，再回到入门章节动手实践；在意内容来源与模板权限的读者，建议重点阅读安全模型。

## 关于 Hugo

Hugo 是用 [Go](https://go.dev) 编写的静态站点生成器，针对速度做了优化，并以灵活性为设计目标。凭借先进的模板系统与快速的资源管道，Hugo 能在数秒、很多时候是更短的时间内渲染出完整站点。

由于框架灵活、支持多语言，并具备强大的分类系统，Hugo 被广泛用于创建企业、政府、非营利组织、教育、新闻、活动和项目站点，也常用于搭建文档站点、图片作品集、落地页、商业与个人博客，以及简历和 CV。

开发期间可以使用 Hugo 内置的 Web 服务器，即时看到内容、结构、行为和呈现方式的变化；完成后再把站点部署到自己的主机，或将改动推送到 Git 服务商，由它执行自动化构建与部署。借助模块，还可以通过公开或私有 Git 仓库，与其他项目共享内容、资源、数据、翻译、主题、模板和配置。
