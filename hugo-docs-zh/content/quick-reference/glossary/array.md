## 数组

_数组_（array）是带编号的[元素](g)序列。与 Go 的[切片](g)数据类型不同，数组的长度固定。数组中的元素可以是[标量](g)、切片、[映射](g)、页面或其他数组。

参见：[Go 语言规范：数组类型](https://go.dev/ref/spec#Array_types)
