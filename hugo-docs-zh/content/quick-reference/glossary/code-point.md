## 码点

_码点_（code point）是 Unicode 标准为每个字符分配的唯一编号。例如拉丁大写字母 `A` 的码点是 `U+0041`，emoji 🎉 的码点是 `U+1F389`。

参见：[码点（维基百科）](https://en.wikipedia.org/wiki/Code_point)
