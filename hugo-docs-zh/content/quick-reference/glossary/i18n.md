## 为什么重要

在 Hugo 里 `i18n` 同时指两样东西：项目根下的 `i18n` 目录（放界面字符串的翻译表）和模板里的 `i18n` 函数（按 key 取当前语言的文案）。它负责的是界面文案，而页面正文的翻译靠语言维度和按语言组织的 `content/` 目录，两者互不替代。最常见的症状是页面上直接显示未翻译的 key 或英文原文：前者说明翻译表里缺少该语言的条目或 key 拼错，后者说明内容目录里没有对应语言的版本或语言没启用。
