IANA 是 Internet Assigned Numbers Authority（互联网号码分配机构）的缩写，这是一个非营利组织，负责管理全球 IP 地址、自治系统号、DNS 根区、媒体类型以及其它互联网协议相关资源的分配。

参见：[IANA 简介](https://www.iana.org/about)
