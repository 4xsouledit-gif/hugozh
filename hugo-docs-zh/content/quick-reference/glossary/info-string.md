信息字符串（info string）是围栏代码块中起始围栏之后的文本。第一个词指定代码示例的语言。Hugo 会把其余内容解析为以空格或逗号分隔的属性。

参见：[Info strings](https://spec.commonmark.org/current/#info-string)
