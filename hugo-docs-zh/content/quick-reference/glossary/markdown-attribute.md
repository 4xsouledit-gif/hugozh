Markdown 属性（Markdown attribute）是附加到 Markdown 元素上的键值对。这些属性通常用于在元素渲染为 HTML 时为其添加 `class`、`id` 等 HTML 属性。它们让你可以扩展基本 Markdown 语法，为内容添加更多语义或样式钩子。

参见：[Markdown 属性](/content-management/markdown-attributes/)
