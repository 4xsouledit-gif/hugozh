模块（module）是由[components](g)打包而成的组合，其中可以包含[archetypes](g)、资源、内容、数据、模板、[translation tables](g)和静态文件。一个模块可以是一个[theme](g)、一个完整的项目，也可以是一个或多个构件组成的更小集合。
