项目（project）是用于生成一个或多个 [sites](g) 的 [components](g) 集合。虽然一个项目可能只包含单个站点，但 Hugo 允许单个项目基于 [language](g)、[role](g) 和 [version](g) 生成站点矩阵。项目是构建中所有站点共用的资源与逻辑的父容器。
