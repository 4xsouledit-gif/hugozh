资源获取器（resource getter）为基于路径的查找提供资源。常见的资源获取器包括：

- 资源切片，例如 `slice $resource1 $resource2`
- [`Resources.Mount`][] 的返回值

[`Resources.Mount`]: /methods/page/resources/#mount
