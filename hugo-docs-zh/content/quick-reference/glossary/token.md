_标记_（token）是格式字符串中的标识符，以冒号开头，渲染时被替换为某个值。在以下情况使用标记：

- 配置[文件缓存][file caches]、[前置元数据][front matter]和[永久链接][permalinks]
- 本地化[日期][dates]
- 在前置元数据中设置 [`url`][]
