_翻译表_（translation table）是 `i18n` 目录中的 JSON、TOML 或 YAML 文件，按 [RFC 5646][] 命名，保存单一语言的译文。

[RFC 5646]: https://datatracker.ietf.org/doc/html/rfc5646
